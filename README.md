# Обработка транзакций

Проект для фильтрации и сортировки списка транзакций.

## Цель проекта

Проект предоставляет функции для обработки списков транзакций:

- **Фильтрация по статусу** (`state`) — функция `filter_by_state`
- **Сортировка по дате** (`date`) — функция `sort_by_date`

Функции безопасны: отсутствие ключей не приводит к ошибкам, используется метод `.get()`.
